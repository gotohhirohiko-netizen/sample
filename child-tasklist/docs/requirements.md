# 要件定義書 — 子ども遠征タスクリストアプリ

version: 0.1(ドラフト) / 対象: 家族利用専用 PWA(Progressive Web App)

## 1. 背景・目的

- 子どもがスポーツ等で遠征する際、朝・昼・晩にやるべきこと(持ち物準備、体温記録、水分補給、就寝準備 等)をチェックリスト化し、忘れずに確実に実行できるようにしたい。
- 親は自宅・現地から離れている場合があるため、子どもが実行したかどうかを**親のスマホに通知**で把握できるようにしたい。
- 家計簿アプリ(`web/`)と異なり、**親・子2台以上の端末間でのデータ共有とプッシュ通知**が必須要件となるため、バックエンド(Supabase)を新たに導入する。

## 2. 想定利用者・利用環境

| 項目 | 内容 |
|---|---|
| 利用者 | 家族(親1名以上、子ども1名〔将来的に複数対応〕) |
| 配布方法 | App Store配布なし。GitHub PagesでホストしたURLを親・子それぞれのスマホでSafari「ホーム画面に追加」してPWAとして利用する |
| 対応環境 | iOS Safari 16.4以降(ホーム画面追加時のみプッシュ通知が利用可能)。Android Chromeでも動作する想定 |
| 端末 | 親のスマホ・子のスマホ、それぞれ1台ずつ(v1では1台/人を前提とする) |

## 3. 機能要件

### 3.1 チェックリスト項目の設定(親)

- 親が項目(タイトル・時間帯)を設定する
- 時間帯は「朝・昼・晩」の3区分とし、それぞれ目安時刻(例: 朝=07:00)を設定できる
- 項目は追加・編集・削除・並び替えができる
- 設定した項目は自動的に子どもの端末に反映される(同期)

### 3.2 チェックリストの実行(子)

- 子どもは当日のチェックリストを時間帯別(朝・昼・晩)に表示し、完了した項目にチェックを入れられる
- チェックは子ども自身の端末からのみ行う(v1)

### 3.3 日次リセット

- チェックリストの項目自体(テンプレート)は親が設定した内容を毎日同じものとして使い回す
- チェック状態は日付ごとに独立して記録し、日付が変わると全項目が未チェックの状態に戻る

### 3.4 リマインド通知

- 各項目の目安時刻を過ぎても未チェックの場合、子どもの端末にプッシュ通知でリマインドする
- 通知後も一定時間(既定30分、設定は運用で調整)ごとに、チェックされるまで繰り返しリマインドする
- 深夜等への通知集中を避けるため、時間帯ごとに繰り返し打ち切りの締め時刻を設ける(例: 朝の項目は次の「昼」区分の目安時刻を過ぎたら朝の分の繰り返しは止める)

### 3.5 完了通知(親)

- 子どもが項目をチェックした際、親の端末にプッシュ通知が届く(例:「◯◯(子の名前)が『歯磨き』を完了しました」)
- 親の「今日の進捗」画面では、チェック状況がリアルタイムに反映される(通知を見逃してもアプリを開けば最新状態がわかる)

## 4. 非機能要件

### 4.1 セキュリティ・プライバシー

- 家族単位でデータを分離する(招待コードで家族を紐付け、他家族のデータにはアクセスできない)
- 認証は端末ごとの匿名認証(Supabase Anonymous Auth)を用い、氏名等の個人情報の入力は必須としない
- Supabaseへの通信はTLSで暗号化される

### 4.2 コスト

- Supabase無料プランの範囲内で運用する(本アプリ専用の新規プロジェクトを作成し、家計簿アプリ用のプロジェクトとは分離する)
- ホスティングはGitHub Pagesを利用し、費用はゼロとする
- データ量は将来的に子ども2人・項目十数個規模でも無料プランのDB上限(500MB)に対して十分小さい(詳細はarchitecture.md参照)

### 4.3 可用性

- 通知配信はWeb Push標準(VAPID)を用いる。iOSでは「ホーム画面に追加」したPWAでのみ通知が届くため、初回利用時にその案内を表示する
- 通知の許可はユーザー操作(ボタンタップ)を起点に要求する(自動プロンプトはブラウザ仕様上不可)

## 5. スコープ外(v1では対応しない)

- 子ども複数人への対応(データモデル上は複数人を見込むが、UIは1人分のみ実装)
- 項目ごとの繰り返し曜日設定(v1は「毎日同じリスト」のみ)
- チェック取り消し理由の記録、コメント機能
- プッシュ通知が届かない場合のSMS/メール等の代替通知手段
- 複数の親アカウントへの同時通知の細かい制御(v1では家族内の親ロール全員に通知)

## 6. 将来拡張ポイント

- 子ども複数人のUI対応(タブ切り替え等)
- 曜日別・特定日限定のチェックリスト
- 遠征期間(開始日・終了日)の設定と、期間外は通知しない機能
- 親が個別にリマインド間隔を項目ごとに調整できる設定画面
